# Pactulys — page de présentation

Page statique publiée par GitHub Pages sur https://pactulys.icg-reborns.com.

Le site existe en français (`/`) et en anglais (`/en/`) : pages HTML statiques, styles et scripts communs dans `assets/`. Dépendances externes : Google Fonts et les formulaires Tally de la liste d'attente, ouverts par lien : `jadW1a` en français et `ArKvke` en anglais.
Le fichier `CNAME` indique à GitHub Pages le domaine personnalisé.
